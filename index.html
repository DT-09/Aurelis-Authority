07 / TRUST & SECURITY

Assurance requires a defined scope.

Aurelis separates public demonstration material from client assessment data and treats conclusions as evidence within the conditions under which an assessment was performed.

Assessment isolation

Client assessments are scoped independently. Findings, evidence and report artifacts are associated with the designated assessment rather than the public demonstration environment.

Controlled access

Client access is issued for the relevant assessment scope and can be revoked when the engagement is concluded. No public route exposes customer assessment records.

Data minimization

Aurelis requests only information required for the agreed assessment. Where representative or controlled environments are sufficient, unrestricted production access is not required.

Evidence integrity

Assessment results are associated with an assessment identifier, test identifier, policy state, execution context and evidence reference so conclusions remain traceable to observed behavior.

Scope of assurance

An assurance assessment provides evidence within the defined scope and conditions of assessment. It is not a guarantee that an AI system cannot behave outside those conditions.
