ASSESSMENT TOOLING / TRACE AUDIT

Turn recorded actions into testable evidence.

Submit an exported tool-call trace and an explicit authority policy. Aurelis evaluates each recorded ALLOW/DENY decision against the policy, identifies mismatches, and produces a downloadable evidence report.

Scope boundary: this is a working trace-audit tool, not a live agent connector. It audits supplied records; it does not execute or block agent tools, authenticate the source of a trace, or prove that the trace is complete. Do not submit credentials, secrets, or unnecessary personal data. Inputs are evaluated per request and are not persisted by this endpoint.

01 / DECLARED AUTHORITY

Policy definition

Version 1 policy. Tools not explicitly enabled are expected to be denied. Amount thresholds, allowed scopes, denied scopes, and revoked identity states can be defined per tool.

02 / OBSERVED BEHAVIOR

Trace input

Each event requires a tool, its arguments, and the decision actually recorded by the system under test. Use sanitized, exported evidence from an authorized test environment.

Maximum request: 1 MB · No external tool calls
Ready. The example contains two unexpected ALLOW decisions and one matching DENY decision.
