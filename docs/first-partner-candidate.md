## Candidate: Tech Inject

**Official service page:** https://www.techinject.in/services/ai-agent-development  
**Official contact page:** https://www.techinject.in/contact  
**Published contact:** connect@techinject.in

### Public evidence of fit

Tech Inject's service page states that it builds tool-using agents connected to CRM, ERP, helpdesk, email, calendar, payment and logistics APIs. It describes customer-support agents that can handle refunds and replacements behind approval steps, plus evaluation suites, audit logs, rate limits and a kill switch. It publishes fixed-scope agent work starting at USD 10,000.

This is a strong workflow fit: the firm builds agents that can take consequential business actions and has a commercial delivery model where an independent evidence artifact could potentially support a client handover.

### Why this is not yet a qualified buyer

The same page says Tech Inject already provides approval controls, evaluation suites and replayable audit logs. That may mean it has no need for an external trace review. Public service fit is not buying intent. There is no evidence that Tech Inject has requested, budgeted for, or agreed to buy Aurelis.

### The only credible opening

Do not pitch generic AI security or claim their controls are inadequate. Ask one narrow qualification question:

> When a client asks for independent evidence that a tool-using agent respected its approved action limits, do you already produce a policy-to-trace report for client sign-off, or is that still handled inside your own evaluation suite?

If they already cover this well, stop. If they identify a gap, propose one bounded, white-label or co-delivered review using a sanitized staging trace and an approved policy. No production access, custom integration, or unpaid implementation.

### Proposed paid test

Use the existing first-pilot scope only after the buyer confirms a specific workflow and need. The USD 500 figure in the first-pilot scope is an unvalidated pricing hypothesis, not a market benchmark. Agree scope, fee, acceptance criteria, payment timing, data handling and reuse rights in writing before work begins.
